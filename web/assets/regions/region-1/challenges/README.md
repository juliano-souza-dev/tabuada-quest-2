Regras:

- composição vertical 9:16;

- esses dados são preenchidos dinamicamente por HTML/CSS/JS;
- o cenário deve corresponder ao tema visual da Ilha;
- não usar numeração técnica "Ilha X" dentro da arte;
- usar somente o nome narrativo da Ilha;
- reduzir caveiras e priorizar aventura, magia e exploração.
