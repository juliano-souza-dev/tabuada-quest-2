# El Colombo — animação de viagem

Pasta canônica para a navegação do navio **El Colombo**.

Arquivos:

- `el-colombo-ocean-navigation.json` — movimento do navio, rastro e espuma;
- `images/el-colombo.webp` — navio;
- `images/ocean-background.webp` — fundo real 941 × 1672.

Contrato visual:

- o background real compõe a tela inteira;
- o Lottie é transparente e não desenha céu ou oceano sintéticos;
- a proa do El Colombo aponta para a esquerda, então o deslocamento é da direita para a esquerda;
- rastro e espuma acompanham o navio;
- o mesmo conjunto é usado na viagem e no loader do desafio.
