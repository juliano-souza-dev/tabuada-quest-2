# Artes remasterizadas — Aventura dos Mares

Assets novos para a tela inicial, produzidos sem alterar o código do jogo.

Direção visual: aventura pirata infantil e mágica, com identidade própria; sem personagens, logotipos ou símbolos de franquias existentes.

## Otimização

Todos os arquivos são WebP. Fundos e banners usam qualidade 85–86; elementos de interface com transparência usam qualidade 88 e preservam o canal alpha. Isso reduz o peso sem comprometer a leitura em telas móveis.
